  ## 🚀 Core Features

- **Dynamic Video Masking** – Cinematic scroll-triggered video shapes that reveal content with fluid transitions.
- **GSAP-Powered Smooth Scroll** – Ultra-smooth navigation experience using GreenSock for professional inertia-based scrolling.
- **Bento Grid Layout** – A high-end, responsive interactive grid system that organizes content with a gaming-hub aesthetic.
- **Parallax 3D Hover Effects** – Depth-defying interactions on cards and elements using Framer Motion and CSS perspective.
- **Interactive Audio Feedback** – Contextual gaming sound effects triggered by hover and click states to deepen immersion.
- **Mobile-First Responsive Design** – Zero-compromise visual fidelity across all devices and major web browsers.


## 🤸 Quick Start

Follow these steps to set up the project locally on your machine.

### Prerequisites

Make sure you have the following installed:
* **Git**
* **Node.js** (LTS Version)
* **npm** (Node Package Manager)

### 1. Cloning the Repository
1. Clone
```
git clone [https://github.com/altZerra/ZentryInspired.git](https://github.com/altZerra/ZentryInspired.git)
cd ZentryInspired
```
2. Installation
   
Install the project dependencies using npm:
```
npm install
```
3. Running the Project
```
npm run dev
```
Open http://localhost:5173 in your browser to view the project.
